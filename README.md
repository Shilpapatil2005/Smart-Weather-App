# \# SkyCast – Smart Weather Forecast and Intelligence System

# 

# SkyCast is a Java-based weather forecasting web application that provides real-time weather information through an interactive and responsive dashboard.

# 

# \## Features

# 

# \- Real-time weather information

# \- City-based weather search

# \- Hourly weather forecasts

# \- 7-day weather forecasts

# \- Air-quality monitoring

# \- Favourite cities

# \- Search history

# \- Responsive user interface

# \- Database integration

# 

# \## Technologies Used

# 

# \- Java

# \- Java Servlets

# \- JSP

# \- JDBC

# \- MySQL / SQLite (update according to your actual database)

# \- HTML, CSS, JavaScript

# \- Apache Tomcat 10

# \- Weather REST API

# 

# \## Installation

# 

# 1\. Clone the repository.

# 2\. Open the project in your IDE.

# 3\. Configure the database.

# 4\. Configure the weather API key.

# 5\. Deploy the application on Apache Tomcat 10.

# 6\. Start the server.

# 

# \## Run Application

# 

# ```text

# http://localhost:8080/WeatherApp/

# ```
